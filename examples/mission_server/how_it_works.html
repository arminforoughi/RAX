B

Band AI — Agent Team

Band gives the robot a persistent identity and a shared room where multiple agents collaborate:

  • Planner breaks the task into steps.
  • Executor calls the robot.
  • Critic judges success or failure.
  • Memory and Learner update knowledge.
A

Actian VectorAI DB — Memory

Every attempt is embedded and stored as a vector:

  • Task text → semantic embedding.
  • Params used → grasp configuration.
  • Outcome → success or failure.

Before a new pick, the agent searches similar past episodes and starts from what worked.

P

Pioneer AI — Self-Improvement

Pioneer runs the specialist model that picks grasp parameters:

  • Inference returns JSON params (aim offset, approach steps, trim, pitch).
  • Failed attempts become training examples.
  • A Pioneer fine-tune job retrains the specialist on the robot's own data.
Files you can point to:
agent.py runs the self-learning loop.
memory.py talks to Actian (or local JSONL fallback).
learner.py calls Pioneer and collects training data.
self_learn_server.py serves the UI and proxies the robot.
