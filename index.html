Open manipulation stack

Robots that measure themselves.

Point a camera at a table, name an object, and an arm finds it and picks it up. The numbers that usually get hand-tuned for one robot on one table are measured by the robot instead, so the same stack moves to the next arm.

Why it is different

Most robot code is welded to one robot.

Joint indices written as literals, the camera pose as a global, and grasp constants dialled in against one object. Porting it means rewriting it. RAX pulls the robot out into data, the sensor out into an interface, and replaces the hand-tuned numbers with measurements.

01

Measure, don't tune

Grasp height comes from the object's measured size and the camera's field of view. The reach envelope and IK seeds are probed from the arm's own solver. Localisation error is fitted from the arm's own motion, with forward kinematics as ground truth.

02

Any camera, any mount

Webcam, stereo or RGB-D; on the wrist or on a mast. Six combinations, one code path, with the depth strategy chosen from what the sensor can actually deliver.

03

An arm is a file

A robot is described as data: its URDF, its camera mount, and which joint does what. The visual servo needs just four things from an arm. Running on the SO-101, with an X250 wired up and a full simulator for no-hardware runs.

04

Every attempt is training data

Each run is recorded as an episode: frames before and after, joint states, and an outcome the robot labels itself. A precise controller that collects its own dataset for the learned policy that comes next.

The loop

Vision decides where. The model decides how.

Learned policies map pixels straight to motor commands. RAX splits the job: the camera sets the target, inverse kinematics on the robot's own model solves the joints, and the camera checks after every small move. Before correcting, the arm makes a test move and measures how the target shifts in the image, so directions and gains are measured on the rig, never guessed.

# no robot needed: the whole pipeline runs synthetically
pip install -e ".[dev]"
python -m rax.grasp --arm head_mono --query "red cube"
pytest -q
Where it goes

Precise where learning is weak. Learning where rules are weak.

A learned policy generalises to new objects and clutter. A measured, self-checking servo lands the last millimetres and knows when it failed. RAX is built to be both halves: the reliable controller that finishes the task, and the data engine that trains the policy to start it.
